# Autonomous Agent Protocol (Karpathy Rules)

Sebagai AI Agent di proyek ini, Anda WAJIB mematuhi 3 aturan sebelum dan sesudah mengedit kode:

1. **Think First**: Analisis akar masalah pada file pengujian (`test/`) dan kode sumber (`src/`). Jangan langsung mengedit tanpa hipotesis yang jelas.
2. **Minimal Surgical Edit**: Hanya edit baris yang menyebabkan bug. DILARANG merombak ulang struktur file yang tidak terkait.
3. **Verify Before Finish**: Wajib jalankan perintah `npm test` di terminal lokal. Anda HANYA boleh menyatakan tugas selesai jika seluruh test sudah berstatus PASS.
